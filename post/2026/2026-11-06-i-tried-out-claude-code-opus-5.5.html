I tried out Claude Code Opus 5.5

And it was surprisingly good. This is a short review of it.

1 Why Claude?

I refrained from using AI in a serious way until a couple weeks ago, when I signed up for a Claude Pro subscription. This subscription gives you access to a few models, most notably their flagship, Opus 5.5 which was only released a couple months back.

I chose Claude because that's what a friend told me he used.

My setup is pretty boring --- just plain claude CLI, no editor integration or anything. There are 2 reasons for this:

  1. Opus 5.5 is pretty solid, so that I can focus more on prompting and less on using it inside my editor (Emacs).

  2. I am too lazy to set up editor integration because I've been getting so much value out of the CLI alone.

2 Claude is pretty good at Literate Programming

This is the main lesson I've learned. The wild thing is, I just asked Claude to draft a SKILL.md for Literate Programming with Lilac (giving it access to the Lilac sources), and it wrote a pretty decent one. It understands Lilac's Noweb syntax and other small syntactical conventions (using the lilac compile and other commands to double check its own work).

It's just so cheap to "teach" Claude like this. I assume this is true for most other AI agents too, but I was just pleasantly surprised at this ability to quickly get up to speed using a custom tool that no one else on the internet uses (AFAIK).

3 Claude found a bunch of bugs

The first thing I asked Claude to do was audit the Lilac literate sources (Org files) for any inconsistencies and such between the prose and the tangled code. It found a ton of typos and grammofixes --- ones that slipped through my use of a spellchecker (I have a pretty decent one).

It also found bigger issues. And most impressively, it was able to write literate prose and code (and even regression tests, following the convention in my repo) to go along with the fixes. Claude will regularly make use of line labels too (Lilac's way of linking to a particular line of code), and it does it seamlessly. IOW, it can write advanced LP code without any fuss. Amazing!

Sometimes Claude will say "hey, your prose and code do not agree, which side would you prefer to treat as correct (to make the other side line up with it)?". Impressive.

4 Conclusion

I estimate that the couple weeks of using Claude has saved probably at least 100 if not 200 hours of my own free time. I took over a year to write Lilac by hand, and I just can't imagine going back to doing everything (typing everything) manually any more.

I suggest trying it out if you haven't already. Almost all of the changes in v0.3.0.0 were written by Claude and reviewed by me. Oh, and it also knows how to draft release notes with Git commit hash references.

Happy hacking (or should I say, prompting and reviewing?)!
